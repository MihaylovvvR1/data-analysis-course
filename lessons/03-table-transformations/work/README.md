## A Разворот сводки

В decisions.csv одна строка содержит одну ипотечную запись, а в organizations.csv - имя одной организации за отчётный год.
В длинной сводке одна строка содержит число записей для организации, года и исхода.
Ключ справочника lei и activity_year известен и уникален, сумма n равна 6830.

Размер wide_task 314 × 3, уровни индекса lei и activity_year.
Для исходов 1, 2 и 3 получилось 20, 252 и 170 пустых ячеек соответственно.
Пустая ячейка означает, что в сохранённом отборе у этой организации за указанный год не было записей с таким исходом.
Для pivot каждой паре из строки и столбца должно соответствовать одно значение n, поэтому сочетание lei, activity_year и action_taken должно быть уникальным.

## C Сохранность исходных значений

После сортировки по source_row все семь исходных полей совпали.
В отдельной копии первая loan_amount увеличена на 1 доллар. Точное сравнение обнаружило изменение.
Проверка длины подтверждает только количество строк. Сумма или другое значение в строке может измениться при той же длине таблицы.

## D Покрытие неполного справочника

Из 6830 записей и учебного справочника с 469 строками left JOIN сохранил все 6830 записей.
У 25 записей нет совпадения справа. При inner JOIN остались 6805 записей, а множество потерянных source_row точно совпало с unmatched.csv.
Повтор первой строки справочника дал каждой из 25 записей этой организации два совпадения, поэтому без validate получилось 6855 строк.
Сначала проверяем правый ключ и выясняем причину повтора. Одинаковую повторную доставку можно убрать после проверки, а разные версии нужно уточнить у поставщика. После исправления повторяем соединение с many_to_one и проверяем покрытие.

Сохранены [unmatched.csv](../results/unmatched.csv) и [join_audit.json](../results/join_audit.json).

## E Передача профиля

Полный профиль сохранён в [organization_profile.csv](../results/organization_profile.csv).

## Итог

Вопрос работы какова доля одобрений по организациям в учебном отборе HMDA.
Использованы decisions.csv и полный organizations.csv по округу Колумбия за 2023 год.
Одна строка профиля описывает одну организацию за отчётный год.
Имена добавлены левым соединением по lei и activity_year с проверкой many_to_one для записей и one_to_one для профиля.
У всех 6830 исходных записей нашлось имя, исходные поля сохранились, а сохранённый профиль прошёл повторное чтение.
Доля одобрений равна числу записей с исходами 1 и 2, делённому на все записи с исходами 1-3 этой организации в отборе, а по всему набору это 6139 из 6830, или 89,88%.
При сравнении организаций нужно учитывать число записей в каждой группе и то, что доли описывают только данный отбор.
